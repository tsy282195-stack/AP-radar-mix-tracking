# 二维/三维升降维策略说明（双指标降维版）

本快照基于用户提供的“主被动融合系统-异构(1)”最新版，仅修改三维质量降维判据及相关状态记录；成熟 3D `run_filter_adapt_ckf`、成熟 2D IMM-KF、transactional pending/commit、logical ID 映射和量测守恒逻辑不重写。

## 3D -> 2D

三维降维申请只由两个物理指标控制：

1. 径向距离 1-sigma 不确定度 `radial_sigma_m`；
2. 最近一次可靠主动三维距离更新的龄期 `range_age_s`。

默认阈值：

- `joint_radial_sigma_warn_m = 5000 m`
- `joint_radial_sigma_drop_m = 10000 m`
- `joint_range_age_warn_s = 3 s`
- `joint_range_age_drop_s = 10 s`

逻辑：

- `warn3d = radial_warn OR range_age_warn`
- `degrade_request = radial_drop AND range_age_drop`
- `down3d` 作为兼容字段等于 `degrade_request`
- 降维申请仍需连续满足 `joint_down_consecutive` 次（默认 3）
- 真正 commit 仍必须满足成熟 2D branch ready 且 2D/3D 投影一致；否则维持原 3D 正式 owner，不隐藏航迹。

`position95_m`、`radial95_m`、`relative_range_sigma`、`nis_norm` 继续计算，仅作为诊断量，不再直接触发降维。

## 可靠距离时间戳

新增 `last_valid_range_t`：

- 仅在主动量测真正完成有效空间/距离更新时刷新；
- 成熟 3D companion 从 `run_filter_adapt_ckf` 的 `last_active_hit_t` 继承；
- 主动 AE-only 和被动 AE 更新不会刷新该时间；
- streaming schema 从 v8 升至 v9，旧状态恢复时以旧 `last_active_t` 作为一次性兼容代理。

## 2D -> 3D

保留现有快速升级框架：成熟 3D candidate、2/3 主动证据、2D/3D 投影一致、无 pending rebind，并要求 `recover3d`。本版将 `recover3d` 与双指标滞回对齐：

- `radial_sigma_m < joint_radial_sigma_warn_m`
- `range_age_s < joint_range_age_warn_s`

因此旧的 position95/NIS 恢复门不再控制升级，但仍保留为诊断配置。
